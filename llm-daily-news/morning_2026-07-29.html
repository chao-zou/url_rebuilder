#03
arXiv：FARMA / SENTINEL 揭示「Agent 推理记忆」新攻击面
arXiv cs.CR2607.05029🔥 7天高频信号 · 安全

论文《Your Agent’s Memories Are Not Its Own: Forged Reasoning Attacks on LLM Agent Memory and Defenses》提出 FARMA（Forged Amplifying Rationale Memory Attack）：攻击对象不再是「事实条目」，而是 Agent 长期记忆里的「推理链」；配套 SENTINEL 防御框架给出「推理来源可追溯」的解法。

💬 点评

这是过去 Prompt Injection 系列研究的自然演化：当 Agent 开始把推理写进长期记忆，「污染的不是知识，而是思考本身」；防御路径必然向可追溯 + 分层信任推进。

🎯 业务视角

对企业侧：任何自建 Agent 系统的记忆库都要立刻加「推理 provenance」字段（模型 / 时间 / 工具 / trace id），并对写入源分等级；否则一次污染可能长期影响所有下游决策。

🔬 技术背景

FARMA 通过在 tool trace 里嵌合理却错误的推理片段，让 Agent 在后续任务里放大错误结论；SENTINEL 的核心是「推理链条来源审计 + 分层信任 + 冲突消解」。

🔗 上下游影响
