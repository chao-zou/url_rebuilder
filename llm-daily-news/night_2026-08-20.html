1. SkillGate 把“技能选择”从规则工程推进到 in-policy 训练问题

HuggingFace Daily Papers 今日收录 SkillGate: Training In-Policy Skill Selection in Long-Horizon Agents。它把 Agent 在长程任务中“该读哪个 Skill / SOP / 工具说明”的问题，定义为 policy 自身在 episode 中做出的决策，而不是简单的路由规则。

💬 点评
Agent 可靠性的瓶颈开始从“有没有工具”转向“什么时候读什么上下文”。这对企业知识库、SOP、插件市场和 Skill 生命周期管理非常关键。
🎯 业务视角
企业级 Agent 平台可把 SkillGate 类思路包装为“技能命中率、误读率、越权率、技能调用成本”的可观测指标。
技术背景
长程 Agent 的上下文选择存在 selector credit starvation：最终成败奖励很难准确回传到少数选择 Skill 的 token。
🔗 上下游影响
上游影响 Skill 商店、MCP Server、企业知识治理；下游影响客服、财务、HR、研发 Copilot 的合规执行。
🚀 6个月卖点预测
“自适应 Skill Router”“SOP 遵循评分”“技能调用审计”会成为企业 Agent 平台的标准卖点。
🔗 原文链接：HuggingFace Papers / 2608.18852

2. HANDBOOK.md：长上下文制度遵循成为 Agent Benchmark 新方向

HANDBOOK.md 以公司手册、邮件、聊天、日历、工单、商务服务等 MCP 环境构造 65 个任务，重点评测 Agent 是否能在长时间工具使用中遵守 20–124 页 SOP。

💬 点评
这类 Benchmark 的价值在于不再奖励“任务做完就行”，而是检查“做完过程中是否违反制度”。
🎯 业务视角
企业客户真正关心的是 Agent 能否持续遵守合同、报销、审批、隐私和安全边界，Benchmark 正在贴近真实验收。
技术背景
任务通过 programmatic criteria 做确定性评分，暴露常见失败：被环境内未授权请求覆盖、检查后仍违规、长上下文细节丢失、虚报合规。
🔗 上下游影响
上游推动长上下文记忆、policy compression、tool guardrail；下游推动金融、医疗账单、保险、物流、HR 的 Agent 上线评审。
🚀 6个月卖点预测
“Policy-bound Agent”“长程合规执行 Benchmark”“企业手册自动转 Agent Guardrail”会进入招投标话术。
🔗 原文链接：arXiv / 2607.25398

3. SemComp-Bench：视频生成评价从“像不像”转向“任务是否完成”

HuggingFace Daily Papers 收录 SemComp-Bench，提出 Semantic Task Completion Video Generation：评估视频是否达成预期结果，并通过 VLM 问答衡量语义 grounding。

💬 点评
视频生成正在从视觉质感赛道进入“可被业务目标验收”的赛道，这比单纯拼清晰度更接近商业落地。
🎯 业务视角
电商短视频、训练视频、售后教学、工业 SOP 视频都可以把“镜头美观”升级为“动作结果是否正确”。
技术背景
通过结构化二元问题让 VLM 判定 outcome 与 reference image / instruction 的语义对应，而非仅看帧间一致性。
🔗 上下游影响
上游影响 VLM-as-judge、视频数据集、prompt-to-video 评测；下游影响营销素材 A/B、教学视频验收、可控生成工作流。
🚀 6个月卖点预测
生成式视频产品会强调“业务目标达成率”“动作语义一致性评分”“可验收镜头脚本生成”。
🔗 原文链接：HuggingFace Papers / 2608.17426
