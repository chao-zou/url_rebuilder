7天高频信号30天持续趋势Agent Skills

1. Code2Skill：从 GitHub 仓库自动提炼 Agent 可复用技能

HuggingFace Daily Papers 今日收录 Grounded Skill Synthesis from Code at Scale for Agentic Intelligence。论文提出 Code2Skill，将代码单元转成 atomic operations、composite workflows 与 recurring patterns，并通过 source-body-blind reconstruction 与 source-aware comparison 验证。作者称其从 19,769 个活跃仓库产出 1,006,822 条 accepted records，覆盖 72 个 protocol-matched evaluations，平均提升 11.7%。

💬点评：这不是又一个 prompt 库，而是把“开发者已经验证过的流程知识”结构化成 Agent 可检索、可调用、可追溯的技能资产。
🎯业务视角：企业内部大量 SOP、脚本、代码仓库都可以成为 Agent 技能来源；真正的护城河不是 prompt，而是经业务系统验证过的操作知识。
技术背景：核心在于 grounding 与 verification：技能来自真实代码证据，再用盲重建和源码感知对比降低幻觉技能进入库的概率。
🔗上下游影响：上游影响代码检索、程序分析和 Skill marketplace；下游影响研发 Agent、IT 运维 Agent、行业解决方案交付。
🚀6个月产品卖点预测：“连接企业代码库，一键生成可验证 Agent Skill Bank”会成为企业 Agent Kit 的高价值卖点。

原文链接：HuggingFace Papers · arXiv · GitHub

7天高频信号Context Engineering

2. ContextPipe：把长程 Agent 的上下文组装变成“数据库优化器”

arXiv 检索显示 ContextPipe: Database-Inspired Context Assembly for Long-Horizon Agents 关注长程 Agent 的 context assembly：运行时决定每轮 prompt 纳入什么、顺序如何、何时压缩历史，并在 context-window 预算和 prompt cache 约束下优化。作者给出 Plan-Bind-Optimize-Execute-Feedback 五阶段框架，初步评估相对 append-only policy 降低 31% token volume、23% LLM calls、9% response time。

💬点评：Agent 上下文不应再靠“把所有历史塞进去”的粗暴策略，而应像数据库查询一样有 optimizer、统计信息、执行计划与回放能力。
🎯业务视角：客服、研发、投研、法务等长链路任务都需要可解释的 context 预算管理；这能直接转化为成本节省与稳定性承诺。
技术背景：Context assembly 同时受 context window、cache 命中、引用完整性和工具观察结果影响，天然适合被抽象为可执行计划。
🔗上下游影响：上游拉动 prompt cache、memory store、trace viewer；下游影响长会话 Agent、复杂工单与多轮数据分析。
🚀6个月产品卖点预测：“Agent EXPLAIN ANALYZE：告诉你每个 token 为什么进上下文、花了多少钱、影响了什么决策”会进入控制台。

原文链接：arXiv 2609.00749
