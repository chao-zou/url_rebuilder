#01
MCP 2026-07-28 规范落地 D+2：无状态核心 + 扩展框架，Claude / AWS / Netlify / Zoom 同步接入
Model Context Protocol · 规范 D+2stateless 核心 · 问世以来最大修订🔥 7天高频信号Agent 工具互操作

Model Context Protocol 于 7/28 发布 2026-07-28 规范——问世以来最大一次修订：移除 initialize 握手与协议级 session，转向 stateless 无状态核心，新增 Extensions 扩展框架、Tasks 异步长任务、MCP Apps、header-based routing、可缓存 list 结果、authorization 加固、正式弃用策略与 Tier-1 SDK。D+1~D+2 内 Claude、AWS Bedrock AgentCore Gateway（一次 UpdateGateway 调用即可启用）、Netlify、Zoom 相继宣布接入。

💬 点评

当一个工具互操作标准把「会话状态」从协议层拿掉，Agent 生态的门槛就从「维护长连接 / session」降到「写一个普通 HTTP 服务」；这比任何单个模型发布都更能决定未来 12 个月「谁的工具能被所有 Agent 调用」。

🎯 业务视角

对企业侧：先盘点现有 MCP server 清单，标出依赖 session 状态的部分排迁移优先级；平台团队可走「AWS AgentCore 一次 UpdateGateway 先合规、再逐步重构」的最短路径，避免被下游 SDK 全量切换打个措手不及。

🔬 技术背景

stateless 意味着 server 变成无 session 的一等 HTTP 工作负载，用 header-based routing + 可缓存 list 结果替代长连接状态；Extensions 把非核心能力挪到受治理的扩展生态，核心协议更稳、扩展更自由。

🔗 上下游影响

利好 MCP 托管 / 网关（AWS AgentCore、Netlify）、Agent 编排框架、工具市场；对依赖「有状态长连接」的旧 Agent 中间件形成迁移压力。
