《The Tasteful Agent》把长周期任务中的“品味”拆成可测指标，指向 Agent 从执行器走向产品合作者。

💬 点评

这类研究的核心不是让模型多调用几个 tool，而是衡量它是否能在模糊目标、冲突约束、隐性偏好之间做出像资深同事一样的判断。

🎯 业务视角

企业 Agent 的卖点会从“自动完成任务”升级到“少返工、会取舍、能解释为什么这么做”，尤其适合销售方案、投放创意、客服升级等半开放任务。

技术背景

长任务 Agent 评测通常涉及任务分解、状态记忆、偏好建模、rubric reward 与轨迹回放；难点在于 reward 不能只看最终答案，还要看过程中是否做了合理权衡。
