1. HuggingFace Daily Papers：视频+音频同步生成与 MoE 边缘推理同场升温

7天高频信号HuggingFace Daily PapersMultimodal

原文：Kandinsky 6.0 Video；Edge0 MoE from SSD

💬 点评：Kandinsky 6.0 Video 把 text/image-to-video 与 44kHz 同步音频放在同一发布叙事里，Edge0 则把 35B MoE 放到单 24GB 机器上讨论，两者共同说明多模态生成和低成本部署正在同时推进。

技术背景：核心关键词是 CrossDiT、audio-video paired training、MoE expert routing、4-bit quantization 与 cache/weight streaming。

🔗 上下游影响：上游利好视频数据、音频数据、显存/SSD I/O 优化；下游影响创意工具、私有云推理、端侧 AIGC 工作站。

🚀 6个月产品卖点预测：“输入商品图+口播文案，一键生成带环境音/口型同步的短视频预览”会成为内容平台和企业营销 Agent 的核心 Demo。

4. ArXiv / Papers With Code：Agentic Retrieval 的效果与成本被同时量化

30天持续趋势ArXiv cs.AI/cs.LGRAG

原文：Beyond Semantic Similarity: Performance and Costs of Agentic Retrieval；Reasoning-Language Alignment in Monolingual RAG；Papers With Code：首页

💬 点评：Agentic Retrieval 的核心结论很清晰：复杂任务能更准，但代价也更重。最新论文报告 agentic retrieval 相比标准 dense retrieval 提升 nDCG@10，但平均查询耗时与 Token 消耗显著上升。

🎯 业务视角：企业 RAG 不能只看 Recall；必须引入“答案价值 / 检索成本 / 延迟预算”三维路由，把简单问题留给普通 RAG，把高价值复杂任务交给 Agentic RAG。

技术背景：ReAct loop、dense retriever、multi-hop reasoning、language-aligned reasoning、nDCG@10、Recall@5。

🔗 上下游影响：上游影响 embedding、reranker、query planner、cache；下游推动合规问答、售前资料检索、代码库理解、医学/法务研究 Agent。

🚀 6个月产品卖点预测：“普通 RAG 秒级回答 + 高价值问题自动升级为深度 Agentic Retrieval”会成为企业知识库产品的标准分层。

维度代表信号适合场景选型提示
公有云/API 模型Artificial Analysis 展示模型 release、Cost/task、Context、Provider；The Batch 提到 Gemini 3.8 Live 可通过 Gemini API、Google AI Studio、Vertex/Vertex AI 等使用。实时语音 Agent、客服/销售 Copilot、代码 Agent、长文档研究、低成本批处理。重点看 latency、tool calling、上下文长度、缓存价格、批处理折扣与企业数据策略。
私有化/开源部署HuggingFace 下载量与 GitHub stars/趋势；Qwen、DeepSeek、MiMo、LTX、GGUF/LoRA 派生生态持续活跃。企业内网知识库、视觉质检、敏感数据分析、边缘设备、离线内容生成。重点看许可证、量化版本成熟度、vLLM/llama.cpp/MLX 适配、显存要求、RAG/Agent 框架兼容。
混合路由社区讨论从“单模型最好”转向“按任务选择模型”。低风险走便宜快模型，高风险走强推理模型；私有数据本地处理，公开资料走公有云。建设 Model Gateway + 评测回放 + 成本归因，避免固定绑定单一模型。
