7天高频信号30天持续趋势Agent Harness

1. Google RRSI：Agent 自我改进开始强调“别过拟合任务集”

HuggingFace Daily Papers 今日收录 RRSI: Regularized Recursive Self-Improvement of Agent Harnesses。论文把 Agent 能力的关键放在 prompts、control flow、tooling、memory、context management 组成的 harness，并用 budget annealing、探索轨迹鼓励、critic 与 pruner 约束自我改进，避免只记住训练任务。

💬点评：这条信号说明 recursive self-improvement 的重心从“模型自己变强”下沉到了“Agent 外壳如何稳定演化”。
🎯业务视角：企业更需要的是可持续优化的 Agent 工程系统，而不是每周更换一次提示词；harness 资产可沉淀为行业 SOP、插件组合和评测集。
技术背景：RRSI 的核心是把候选修改的数量、方向和有效性纳入约束，追求跨任务泛化而不是榜单刷分。
🔗上下游影响：上游拉动 eval harness、trace、tool calling 与 memory 产品；下游影响研发 Agent、客服 Agent、数据分析 Agent 的运维方式。
🚀6个月产品卖点预测：“可自我优化但不过拟合的 Agent Harness Studio”会成为企业 Agent 平台的高阶功能。

原文链接：HuggingFace Papers · arXiv · GitHub

30天持续趋势Video World Model

2. WorldCrafter：视频生成从“短片”走向“可探索世界”

HF Trending Papers 今日靠前的 WorldCrafter 提出带 implicit 3D-aware memory 的 video world model：在长时间、多视角探索中，把历史观察压缩成面向目标视角的 token，再交给视频生成器保持空间一致性。

💬点评：视频模型的产品价值不只在“更像真视频”，而在于能否保持空间记忆、镜头连续与交互可控。
🎯业务视角：对鞋服电商，下一步卖点会是“同一模特/同一商品/同一场景的连续镜头资产”，降低拍摄与剪辑返工。
技术背景：3D-aware memory 解决的是多视角生成中的身份、位置和环境漂移问题，本质是把世界状态纳入生成条件。
🔗上下游影响：上游影响数据合成、游戏引擎和机器人仿真；下游影响广告分镜、互动商品展示、虚拟试穿和自动剪辑。
🚀6个月产品卖点预测：“从单张商品图生成可导航 3D 视频拍摄空间”会成为生成式营销工具的新叙事。

原文链接：HuggingFace Papers · arXiv · GitHub

7天高频信号Agent SecurityThe Batch

3. The Batch：Meta Muse 把个人 Agent 安全做成 VM/权限/审计架构

The Batch 最新一期聚焦 Meta Muse：个人 Agent 可连接浏览器、邮箱、日历、WhatsApp、购物和智能家居等服务，并强调用隔离 VM、sealed runtime cell、credential service、Sentinel 审批与活动日志降低 prompt injection 风险。

💬点评：Agent 安全的成熟标志，是承认模型会被欺骗，然后用系统架构兜底，而不是继续押注“更强 system prompt”。
🎯业务视角：企业客户会越来越关注“Agent 能做什么”背后的权限边界：谁批准、可否回放、能否撤销、敏感凭证是否出现在模型上下文里。
技术背景：隔离执行、凭证代理、untrusted data 标记、外置 classifier 与用户审批绑定，是个人/企业 Agent 的基础安全栈。
🔗上下游影响：上游推动 Agent sandbox、MCP 权限模型和审计日志；下游影响采购、法务、风控与信息安全准入。
🚀6个月产品卖点预测：“Agent 零凭证暴露 + 每一步可审批/可追责”会成为办公 Agent 与客服 Agent 的标准卖点。

5. 公有云模型：从“最强模型”改成“任务级路由”

Artificial Analysis LLM Leaderboard 按 intelligence、price、output speed、latency、context window 等维度比较 250+ 模型；页面显示 Claude Fable 5.1、GPT-6 Astra 位于 intelligence 前排，Celeris-1/Mercury 2 速度突出，Granite 4.2 3B 与 GPT-5.6 Luna 在 cost per task 维度靠前。

技术背景：TTFT 决定首字响应体感，tokens/s 决定生成吞吐，cost per task 决定规模化成本，context window 决定长文档能力。

7. Benedict Evans：AI 不会自动替企业发现该改造的流程

Benedict Evans 在 9 月文章中提醒：AI 降低了做工具的门槛，但企业真正难的是发现哪些任务值得改造、如何让跨部门流程改变，并把临时解决方案制度化为可审计系统。

💬点评：这是一盆很必要的冷水：让员工都拿到 ChatGPT 不等于完成企业 AI 转型。
🎯业务视角：咨询式交付仍有空间：发现流程、定义 KPI、重构责任边界、推动 adoption，比单纯部署模型更关键。
技术背景：企业软件从 improvised 到 institutionalized 的迁移，需要权限、审计、维护、集成和采购决策共同成立。
