1. OpenAI GPT‑Live‑1 API：full-duplex voice 正式进入开发者工作流

公有云模型使用场景

OpenAI 官方发布 GPT‑Live‑1 in the API，主打“同时听和说”的 full-duplex voice、Interruption handling、后台模型/工具委托、长会话稳定性、Telephony support，并给出前端语音层 $0.05/min 的价格。原文链接

💬点评这不是又一个 Voice API，而是把语音层从“转写/合成管道”升级为可调度的前端实时代理。
🎯业务视角客服、导购、预约、坐席辅助会优先受益，尤其适合对打断、沉默、背景噪声敏感的电话场景。
技术背景传统架构依赖 STT→LLM→TTS 串联，GPT‑Live‑1 将听说合并，并把复杂推理委托给后端模型。
🔗上下游影响上游利好语音评测、电话渠道、工具调用框架；下游会压缩传统 IVR 与基础 TTS/ASR 集成商空间。
🚀6个月卖点“像真人一样可打断的 AI 电话员工”“一套 Prompt 管理语气、节奏、动作委托”。

2. 小宇宙《AIGC日报》：DeepSeek v4.1-Flash 与 Causal Encoder-Decoder 叙事升温

小宇宙播客洞察

小宇宙《AIGC日报》今日聚焦 DeepSeek v4.1-Flash：播客称其 763B 总参数、8B 激活参数之外，更受关注的是 Causal Encoder-Decoder 架构、视觉原生输入和多模态部署成本下降；同集还提及 system prompt leaks、Chollet 的开源生态观点和多项行业融资合作。原文链接

💬点评播客把“模型架构路线”放在参数规模之前，这是今天最有价值的叙事变化。
🎯业务视角企业选型会从“最大模型”转向“架构是否适合多模态、成本是否可控、能否私有部署”。
技术背景Decoder-only 之外的结构探索，实际是在为视觉输入、低成本推理和跨模态任务重新分配计算。
🔗上下游影响推理引擎、模型压缩、国产算力适配、VLM 应用链路都会被重新定价。
🚀6个月卖点“低激活参数多模态模型”“视觉 Agent 可私有化落地”“从文本 LLM 到原生 VLM 工作流”。

论文/技术深度
